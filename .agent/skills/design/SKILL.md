# Design Protocol

## 1. Estética Premium

- **Glassmorphism**: `backdrop-filter: blur()` en modales/paneles.
- **Minimalismo**: Sombras suaves, gradientes sutiles, espaciado generoso.
- **Tipografía**: Fuentes sans-serif modernas (Inter/Outfit). Jerarquía clara.

## 2. Color & Dinámica

- **Paleta**: Evitar colores puros. Usar variables CSS HSL. Modo Dark/Light nativo.
- **Interactividad**: Transiciones `0.3s ease`. Feedback visual inmediato (hover/active/spinners).

## 3. Componentes

- **Bordes**: Rounded (8px+).
- **Cards**: Lift effect en hover.
- **Botones**: Padding generoso, sin bordes toscos.

## 4. Stack

- **CSS**: Vainilla + CSS Variables. NUNCA estilos inline.
